# Описание транзакций процесса обработки платежа системой OrchestrPay



| Транзакция | Описание | Тип | Компенсация
| --- | --- | --- | --- |
| CREATE_PAYMENT | Система создает платеж, запускает процесс обработки платежа | компенсируемая | CANCEL_PAYMENT |
| CANCEL_PAYMENT | Платеж онулируется | повторяемая | - |
| CHECK_PAYMENT_AVAILABILITY | Система проверяет наличие требуемой суммы на балансе клиента. 2 варианта исхода: Достаточно средств/Недостаточно средств. Достатосно -> PRE_PAYMENT, недостаточно -> NOTIFY_USER_NOT_AVAILABLE, откат саги по цепочке  | компенсируемая | - 
| NOTIFY_USER_NOT_AVAILABLE | Система уведомляет пользователя о нехватке средств на его балансе | повторяемая | -
| PRE_PAYMENT |  Система списывает необходимую сумму с баланса клиента | Компенсируемая | REFUND_USER
| REFUND_USER | Система возвращает сумму на счет клиента | повторяемая | - 
| NOTIFY_USER_REFUND| Система уведомляет пользователя о возврате средств на его баланс | повторяемая | - 
| AUTO_CHECK_PAYMENT | FraudCheck Service проверяет платеж по внутренним правилам. 3 варианта исхода: Разрешено/Запрещено/Ручная проверка. Разрешено/превышено ожидание в 5 секунд -> PAYMENT_TO_CONTERPART. Запрещено -> (PROHIBIT_PAYMENT & NOTIFY_SECURITY) . Ручная проверка -> MANUAL_CHECK_PAYMENT | Компенсируемая | - | 
| MANUAL_CHECK_PAYMENT | Менеджер выполняет ручную проверку платежа. Спустя 20 минут после перевода транзакции в статус ручного разрешения, она будет разрешена поумолчанию. Разрешено/превышено ожидание в 20 минут -> PAYMENT_TO_CONTERPART, запрещено -> (PROHIBIT_PAYMENT & NOTIFY_SECURITY) | Компенсируемая | -
| PROHIBIT_PAYMENT | Платеж отмечается как запрещенный. Откат саги по цепочке. | повторяемая | -
| NOTIFY_SECURITY | Оповещение службы безопасности системы | повторяеамая | -
| PAYMENT_TO_CONTERPART | Система переводит средства контрагенту | Необратимая | -
| NOTIFY_USER_SUCCESS | Система уведомляет пользователя об успешной оплате | повторяемая | -
