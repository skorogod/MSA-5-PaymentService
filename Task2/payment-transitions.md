# Таблица переходов платежа OrchestrPay

## Состояния

| Состояние | Что значит |
| --- | --- |
| NEW | Платёж создан, деньги ещё не списаны |
| DEBITED | Деньги списаны со счёта клиента |
| FRAUD_CHECK | Идёт автоматическая проверка в антифроде |
| MANUAL_REVIEW | Платёж ждёт решения оператора (до 20 минут) |
| APPROVED | Проверка пройдена, можно переводить деньги |
| BLOCKED | Платёж признан подозрительным и заблокирован |
| REFUNDING | Идёт возврат денег клиенту |
| COMPLETED | Деньги переведены контрагенту. Конец |
| REFUNDED | Деньги вернулись клиенту. Конец |
| CANCELLED | Платёж отменён до списания денег. Конец |

## Переходы

| Исходное состояние | Переходное состояние | Событие |
| --- | --- | --- |
| — | NEW | Клиент оформил заказ и начал оплату |
| NEW | DEBITED | Денег на счёте хватает, сумма списана |
| NEW | CANCELLED | Денег на счёте не хватает |
| NEW | CANCELLED | Списать деньги не удалось (ошибка) |
| DEBITED | FRAUD_CHECK | Платёж отправлен на проверку в антифрод |
| FRAUD_CHECK | APPROVED | Антифрод разрешил платёж |
| FRAUD_CHECK | APPROVED | Антифрод не ответил вовремя (сработал cut-off) |
| FRAUD_CHECK | BLOCKED | Антифрод запретил платёж |
| FRAUD_CHECK | MANUAL_REVIEW | Антифрод отправил платёж на ручную проверку |
| MANUAL_REVIEW | APPROVED | Оператор разрешил платёж |
| MANUAL_REVIEW | APPROVED | Оператор не ответил за 20 минут (сработал cut-off) |
| MANUAL_REVIEW | BLOCKED | Оператор запретил платёж |
| BLOCKED | REFUNDING | Запущен возврат денег, служба безопасности получила уведомление |
| APPROVED | COMPLETED | Деньги переведены контрагенту |
| APPROVED | REFUNDING | Перевести деньги контрагенту не удалось |
| REFUNDING | REFUNDING | Возврат не прошёл, система пробует ещё раз |
| REFUNDING | REFUNDED | Деньги вернулись на счёт клиента |

## Как идёт платёж в разных случаях

- **Всё хорошо:** NEW → DEBITED → FRAUD_CHECK → APPROVED → COMPLETED.
- **Антифрод отказал:** NEW → DEBITED → FRAUD_CHECK → BLOCKED → REFUNDING → REFUNDED.
- **Сработал cut-off:** FRAUD_CHECK или MANUAL_REVIEW → APPROVED → COMPLETED.
- **Ручная проверка:** FRAUD_CHECK → MANUAL_REVIEW → APPROVED или BLOCKED.

Клиент получает уведомление при переходе в COMPLETED, REFUNDED и CANCELLED.

Возврат повторяется, пока не пройдёт. Так деньги не «зависнут» между системами, и поддержке не придётся ничего делать вручную.
